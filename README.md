# Cold War: World Strategy — เกมบอร์ดออนไลน์

## วิธีรันบนคอมพิวเตอร์
1. ติดตั้ง Node.js รุ่น LTS จาก https://nodejs.org/
2. แตกไฟล์ ZIP
3. เปิด Terminal/Command Prompt ในโฟลเดอร์นี้
4. รัน `npm install`
5. รัน `npm start`
6. เปิด http://localhost:3000

## วิธีเล่น
- ผู้เล่น 4–10 คนต่อห้อง
- คนหนึ่งสร้างห้องและแชร์รหัส 4 ตัวให้เพื่อน
- เมื่อมีอย่างน้อย 4 คน เจ้าของห้องกดเริ่มเกม
- ผลัดกันทอยเต๋า เดินบนกระดาน และตอบคำถามประวัติศาสตร์
- ตอบถูกได้ 3 คะแนน; ช่องพิเศษอาจเพิ่ม/ลดคะแนน
- เกมมี 4 รอบ (นับรอบเมื่อผู้เล่นทุกคนได้เล่นครบหนึ่งครั้ง)

## เปิดให้เพื่อนเล่นผ่านอินเทอร์เน็ต
ต้องนำโปรเจกต์นี้ไป deploy บนบริการที่รองรับ Node.js และ WebSocket เช่น Render หรือ Railway แล้วแชร์ URL ให้เพื่อน
ไฟล์นี้เป็นต้นแบบพร้อมโค้ดเซิร์ฟเวอร์ ยังไม่ได้เผยแพร่เป็นเว็บไซต์สาธารณะให้อัตโนมัติ
